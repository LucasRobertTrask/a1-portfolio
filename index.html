OC Surfsite

I've been working on a web application for surfing in Orange County. I plan on delivering features that allow surfers to understand the current conditions and forecasts. I will tailor forecasts and current conditions based on historic data and user input about each break location and the conditions necessary for good surf. Currently there exist websites that attempt to provide silimilar live data and forecasting but fail to provide the specific information about each break location neccessary for surfers to use that data and make decisions on the best times to surf. I plan to fill this gap and supply users with this information such that they may learn more about different breaks and schedule the best times to surf for them. Currently I have most the backend data collection and processing complete and plan on finshing the project by the end of the year. The backend pulls from multiple API's and processes the data in python. I plan to use HTML, CSS and Node.js to complete the front end website. Here is the link to the github repository.
